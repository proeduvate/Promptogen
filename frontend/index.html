Groq API Key (via .env)

Groq gives you free access to Llama 3.3 70B one of the most powerful open models available. It's much faster and smarter than local phi3. Get your free key at console.groq.com

1. Go to console.groq.com
2. Sign up free (GitHub/Google login works)
3. Go to API Keys Create API Key
4. Create a .env file and set: GROQ_API_KEY=gsk_...
5. Restart the backend
.env Example
GROQ_API_KEY=gsk_...
